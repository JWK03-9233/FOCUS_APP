# FocusApp 계획

## 만들게 된 이유

공부나 업무 중에 무심코 다른 앱으로 넘어가는 일을 의지만으로 막기는 어렵습니다.
기존 차단 앱들은 대체로 "방해되는 것을 지정해서 막는" 방식이라, 방해 요소가 많고
수시로 바뀌면 목록을 관리하기 번거롭습니다. 이 앱은 반대로 "쓸 것만 허용하고
나머지는 전부 막는" 허용 목록 방식을 택합니다.

## 핵심 동작

* 실행 중에는 지금 화면에 떠 있는 창이 어떤 앱인지 계속 확인합니다.
* 허용 목록에 있는 앱이면 그대로 둡니다.
* 허용 목록에 없는 앱이 앞으로 올라오면 강제로 최소화하고, 마지막으로 쓰던 허용 앱으로 되돌립니다.
* 앱을 종료하지 않고 최소화만 하기 때문에 저장하지 않은 작업이 사라질 위험이 없습니다.
* 작업 표시줄, 시작 메뉴, 작업 관리자 같은 시스템 요소는 항상 예외로 둬서 PC를 못 쓰게 되는 상황을 막습니다.

## 프로필

상황에 따라 허용할 앱 묶음을 프로필로 나눠서 저장합니다.

* 공부용: 공부에 필요한 앱만 허용합니다.
* 업무용: 업무에 필요한 앱만 허용합니다.
* 자유 시간: 차단을 풀거나 최소한의 제한만 둡니다.

프로필은 필요에 따라 추가할 수 있고, 허용 앱은 설정 파일에 저장됩니다.

## 해제할 때의 마찰

이 앱의 가장 큰 특징은 끄기 어렵게 만든 것입니다. 충동적으로 해제하는 것을 막기 위해,
차단을 해제하려면 화면에 나타나는 긴 랜덤 문자열을 직접 입력해야 합니다.

* 붙여넣기는 막아서 반드시 손으로 입력하게 합니다.
* 틀리면 새로운 문자열이 나옵니다.
* 트레이 메뉴의 종료나 프로필 전환도 같은 절차를 거치도록 하는 안을 기본으로 합니다.
* 차단 중에는 허용 목록 편집을 막아서, 목록에 앱을 몰래 추가하는 우회를 방지합니다.
* 오작동에 대비한 비상 해제 수단은 평소에 누르기 어려운 방식으로 남겨둡니다.
  (구현: 트레이의 "비상 해제"를 선택하면 일정 시간(기본 10분)이 지난 뒤에야
  차단이 풀리며, 그동안 차단은 계속되고 언제든 취소할 수 있습니다.)

## 사용 방법

1. 시스템 트레이 아이콘에서 프로필을 고르고 집중 모드를 켭니다.
2. 정한 시간 동안 허용 앱 외에는 자동으로 최소화됩니다.
3. 끝내고 싶으면 트레이에서 해제를 선택하고 랜덤 문자열을 입력합니다.

## 기술 구성

* 플랫폼: Windows
* UI: PySide6 (시스템 트레이 아이콘과 설정 화면)
* 감시: 짧은 주기로 포그라운드 창을 확인하는 허용 목록 감시 방식
* 저장: JSON 설정 파일
