# FocusApp

쓸 앱만 허용하고 나머지는 전부 막는, Windows용 **허용 목록 방식 집중 앱**입니다.

## 동작

* 집중 모드 중에는 짧은 주기(기본 300ms)로 포그라운드 창의 프로세스를 확인합니다.
* 프로필의 허용 목록에 있는 앱이면 그대로 둡니다.
* 허용 목록에 없는 앱이 앞으로 오면 **최소화**하고, 마지막으로 쓰던 허용 앱으로 되돌립니다.
  앱을 종료하지 않으므로 저장하지 않은 작업이 사라지지 않습니다.
* 작업 표시줄, 시작 메뉴, 작업 관리자, 설정 앱 등 시스템 요소와 이 앱 자신은 항상 허용됩니다.

## 해제 마찰

* 해제하려면 화면의 긴 랜덤 문자열(기본 32글자)을 **직접 손으로** 입력해야 합니다.
  붙여넣기·드래그 앤 드롭·일괄 입력은 막혀 있고, 틀리면 새 문자열이 나옵니다.
* 집중 모드 중 종료와 프로필 전환에도 같은 절차가 적용됩니다(설정에서 변경 가능).
* 집중 모드 중에는 설정 창이 읽기 전용으로 열려 허용 목록을 몰래 고칠 수 없습니다.
* 앱이 비정상 종료되어도 세션이 파일에 남아, 다시 실행하면 남은 시간 동안 차단을 이어갑니다.
* **비상 해제**: 오작동에 대비한 수단입니다. 트레이에서 요청하면 지연 시간(기본 10분)이 지난 뒤에야
  차단이 풀리며, 그동안 차단은 계속되고 언제든 취소할 수 있습니다.

## 사용법

`pip install -r requirements.txt` 후 `python -m focus_app` (또는 `scriptsun.bat`)로 실행하면 FocusApp 창이 열립니다.
창은 위에서 아래로 순서대로 쓰면 됩니다.

1. **① 모드 고르기** — 왼쪽에서 모드(공부용·업무용·자유 시간 등)를 고르거나 `+ 새 모드 만들기`로 만듭니다.
2. **② 쓸 앱** — `+ 앱 추가`를 누르면 지금 실행 중인 앱과 설치된 앱이 아이콘과 함께 나옵니다. 쓸 앱을 체크하면 끝입니다.
   목록에 없으면 `.exe` 파일을 직접 찾을 수 있습니다. 모드를 "아무것도 막지 않기"로 두면 시간만 잽니다.
3. **③ 집중할 시간** — 25분·50분·1시간 30분… 중에 고르거나 직접 입력하고 `▶ 집중 시작`을 누릅니다.
4. 집중 중에는 남은 시간, 쓸 수 있는 앱, 막은 횟수가 보입니다. 시간이 끝나면 자동으로 풀립니다.
   중간에 끝내려면 `집중 끝내기…`를 누르고 랜덤 문자열을 직접 입력합니다.

모든 변경은 바로 저장됩니다. 창을 닫아도 트레이에서 계속 실행되며, 트레이 아이콘을 누르면 창이 다시 열립니다.
해제 문자열 길이, 비상 해제 대기 시간, 알림 같은 세부 옵션은 오른쪽 위 `⚙ 설정`에 있습니다.

## 파일 위치

설정과 세션은 `%APPDATA%\FocusApp\` 아래 JSON으로 저장됩니다.

| 파일 | 내용 |
| --- | --- |
| `settings.json` | 프로필, 허용 앱, 감시 주기, 해제 문자열 길이 등 |
| `session.json` | 진행 중인 집중 세션 (해제되면 삭제) |
| `focus_app.log` | 차단 기록과 오류 로그 |

## 개발

```
pip install -r requirements-dev.txt
pytest
```

핵심 로직(`config`, `enforcer`, `unlock`, `session`, `monitor`)은 Qt와 Windows API에 의존하지 않아
어느 OS에서든 테스트할 수 있습니다. 실제 창 감시·최소화는 `winapi.py`(ctypes)를 통해 Windows에서만 동작합니다.

빌드만 하려면 `scripts\build_exe.bat` (결과: `dist\FocusApp\FocusApp.exe`).

## 릴리스

릴리스는 로컬에서 `release.py` 하나로 합니다. (준비물: `gh auth login`, Inno Setup 6)

```
python release.py                  # 현재 버전, GitHub 최신 릴리스, 다음 버전 제안
python release.py 0.4.0 --dry-run  # 무엇을 할지 미리 보기
python release.py 0.4.0            # 실제 릴리스
```

순서: preflight → 테스트 → 버전 bump → PyInstaller → 비밀 파일 검사 → zip → Inno Setup 설치 프로그램
→ GitHub 릴리스(draft로 올림 → 체크섬 확인 → 공개) → 다운로드 주소 확인.

* 변경 내용은 `CHANGELOG.md`의 `## [0.4.0]` 절에 적으면 릴리스 설명과 앱의 업데이트 창에 나옵니다.
* `--urgency recommended`면 앱이 알림으로, `critical`이면 실행하자마자 업데이트 창으로 알려 줍니다.
* 스크립트는 git을 건드리지 않습니다. 끝나면 안내되는 대로 버전 파일을 커밋·push하세요.
* GitHub Actions는 push·PR마다 테스트만 돌립니다.

앱의 `업데이트 확인`은 최신 릴리스의 `FocusApp_Setup_<버전>.exe`를 받아 체크섬을 확인한 뒤,
앱을 끄고 조용히 설치(`/VERYSILENT /DIR=<현재 폴더>`)한 다음 새 버전을 다시 실행합니다.

## 알려진 한계

* 작업 관리자는 항상 허용되므로 거기서 프로세스를 끝낼 수는 있습니다. 세션 파일 덕분에 다시 실행하면 차단이 이어지지만,
  다시 실행하지 않으면 차단되지 않습니다. 완전한 강제가 아니라 "충동적인 해제를 어렵게 하는 것"이 목표입니다.
* 관리자 권한으로 실행된 창은 일반 권한의 FocusApp이 최소화하지 못할 수 있습니다. 그런 앱까지 막으려면 FocusApp을 관리자 권한으로 실행하세요.
